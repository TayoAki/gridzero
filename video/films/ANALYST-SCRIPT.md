# The data analyst film: script

One person, Ana, a data analyst. The film follows her whole job in order: from an orders export to a filtered
report she can hand over, with the query, the rows and the working kept beside it. Silent, words on cards,
108 seconds, starts from an empty account and opens on the finished result.

Truth notes: every screen is the real app, captured from the current build with 1,200 made-up orders. No agent
appears, so nothing is staged; the SQL, the card, the rows and the Python cell all ran. Nothing here is released
yet, and the end card says so. No figures for time saved appear, because none have been measured.
