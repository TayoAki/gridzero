How it was measured

  • Data: node bench/dataset.mjs <rows> <file>, seeded, so every product imports byte-identical files (the 1M-row file is about 70 MB).
  • GridZero: node bench/gridzero.mjs <control URL> runs every task through the same API and socket the browser uses. Drawing in the browser is not timed.
  • Other products: timed by hand with a stopwatch, middle of three tries, on the same machine and network. Hand timing cannot resolve much under 300 ms.
  • Imports include uploading the file from this machine, so they depend on its upload speed.
